# Météo Maroc
Projet Data Engineering consacré à la collecte et à l'analyse des données météorologiques du Maroc.
Les données seront récupérées depuis une API météo à l'aide de Python.
Elles seront nettoyées, transformées et stockées dans PostgreSQL.
Objectif : construire un pipeline ETL et visualiser les tendances météorologiques des villes marocaines.# meteo-maroc
